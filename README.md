**専門知識やアカウント登録は一切不要です**。以下の手順どおりに進めてください。

## 1. ファイルをダウンロードする

1. このページの上のほうにある緑色の **「Code」** ボタンをクリックします。
2. 開いたメニューの一番下にある **「Download ZIP」** をクリックします。
3. `TwiCasLiveHelper-main.zip` のような名前のファイルが、パソコンの
   「ダウンロード」フォルダに保存されます。

※ 「Clone」「git clone」「SSH」といった項目が同じメニューに出てきますが、
　 それらは開発者向けの機能です。**使う必要はありません。**

---

## 2. ダウンロードしたファイルを展開する(解凍する)

ダウンロードしたzipファイルは、そのままでは中のファイルを使えません。
「展開(解凍)」という作業が必要です。

**Windowsの場合**

1. ダウンロードした `TwiCasLiveHelper-main.zip` を右クリックします。
2. メニューから **「すべて展開」** を選びます。
3. 表示された画面でそのまま **「展開」** ボタンを押します。
4. 同じ場所に、zipではない普通のフォルダ(`TwiCasLiveHelper-main`)ができます。

**Macの場合**

1. ダウンロードした `TwiCasLiveHelper-main.zip` を**ダブルクリック**します。
2. 自動的に展開されて、同じ場所にフォルダ(`TwiCasLiveHelper-main`)ができます。

## 5. うまくいかないとき

**Q. 「Download ZIP」が見当たらない**
A. まず緑色の「Code」ボタンをクリックしてメニューを開いてから探してください。
「Code」ボタンはページの右上寄り、ファイル一覧のすぐ上あたりにあります。

**Q. zipファイルをダブルクリックしても何も起きない(Windows)**
A. ダブルクリックでは中身が見られるだけで、展開はされません。
右クリックして「すべて展開」を選んでください。

**Q. ダウンロードしたフォルダの中にアプリ本体が見当たらない**
A. `ForWindows`または`ForMacOS`フォルダの中を確認してください。
一段階フォルダを開く必要があります。

**Q. Windows/Macで「安全でないため開けません」のような警告が出る**
A. 初回起動時によく出る警告で、正常です。それぞれのフォルダ内の
`MANUAL.pdf`に対処方法(許可のしかた)を載せています。
